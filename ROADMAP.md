# Roadmap

Implemented: local rendering, five levels, grid reveal/highlight, three themes, stickers, transitions and preview seeking.

Planned, with no committed dates:

- Save and reopen projects.
- Multiple rounds and card combinations per level.
- Better error handling, media validation and export cancellation.
- Beat detection and audio alignment tools.
- English interface and improved accessibility.
- Portable font handling and testing on other operating systems.

There are no verified public adoption or download statistics yet. Feedback from real users will guide priorities.
